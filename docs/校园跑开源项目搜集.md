# 校园跑（刷校园跑）相关开源项目搜集提示词

## 任务背景
用户需要搜集 GitHub 和 X（Twitter）上与「刷校园跑」相关的开源项目，优先星标较高、相对权威的项目。  
后续补充需求：特别关注「悦跑世界」相关项目。

### 2. 「悦跑世界」专项情况

**结论：目前没有找到针对「悦跑世界」专门开发、星标较高的开源项目。**

- 「悦跑世界」是由悦跑世界（广东）科技有限公司开发的校园跑步管理 App（包名类似 `com.joyrunworld.app`），用于高校强制跑步打卡、围栏、配速/步频记录和后台评分。
- 与「悦跑圈（JoyRun）」不是同一个产品。

### 3. X（Twitter）情况
- 主要是学生讨论和求推荐。
- 比较突出的是 mockrunning 作者 @yinsuecci 在 2026 年 9 月底发帖宣传开源工具（互动较高）。
- 有帖子提到刷跑服务存在信息差和商业化。
- 没有特别权威大 V 主导的讨论。

## 风险与注意事项
- 这些项目本质上是模拟 GPS 轨迹 / 协议自动化工具，用于完成学校强制的校园跑任务。
- 多数 README 明确写明「仅供学习研究，请勿用于违反学校规定，后果自负」。
- 实际使用存在被检测、账号封禁、成绩作废、纪律处分等风险（尤其使用易盾等强风控的 App）。
- 搜索时容易混入「校园跑腿」（代取快递等）项目，需注意区分。

## 给本地 Agent 的后续任务建议
1. 如果用户有具体学校名称 + 使用的 App（如悦跑世界、运动世界校园、闪动校园、步道乐跑等），请针对性搜索 `学校名 + 校园跑` 或 `App名 + github`。
2. 可进一步验证以上仓库的最新星标、更新时间和实际可用性。
3. 关注是否有新出现的针对「悦跑世界」的协议逆向或自动化仓库。
4. 整理时优先列出星标 > 50 且近期仍有更新的项目。
